# تنظیمات عمومی Theme Management

## هدف

مدیر باید بتواند بدون ویرایش کد، هویت بصری و تنظیمات عمومی وب‌سایت را کنترل کند.

## موارد قابل مدیریت

- Logo اصلی
- Logo جایگزین در صورت نیاز
- Favicon
- عنوان سایت
- توضیح کوتاه سایت
- اطلاعات پایه برند
- تصویر پیش‌فرض Open Graph در صورت استفاده
- تنظیمات عمومی Presentation که در چند صفحه استفاده می‌شوند

## محل مدیریت

رابط مدیریتی اختصاصی در WordPress Admin در نظر گرفته شود:

```text
WordPress Admin
└── WooGit Theme
    ├── تنظیمات عمومی
    ├── صفحه اصلی
    ├── قابلیت‌ها
    ├── روش کار
    ├── Pricing
    ├── FAQ
    ├── Footer
    └── شبکه‌های اجتماعی
```

محل دقیق منو باید با معماری واقعی Theme هماهنگ شود، اما نباید به Admin Console افزونه تبدیل شود.

## تصاویر

تمام تصاویر از WordPress Media Library انتخاب شوند. Theme باید ID/reference رسانه را نگه دارد، نه Base64 یا فایل داخل Theme.

برای تصاویر مهم مانند Hero، در صورت نیاز نسخه Desktop و Mobile جداگانه قابل تنظیم باشد.
