# Footer، اعتماد و اطلاعات تماس

## Footer

### اطلاعات تماس

- شماره تماس
- Email
- آدرس
- ساعات پاسخ‌گویی در صورت نیاز

### متن‌ها

- متن معرفی کوتاه
- Copyright
- متن‌های قانونی یا اطلاع‌رسانی کوتاه
- CTA در صورت وجود

### لینک‌ها

- Privacy
- Terms
- Documentation
- Support
- سایر لینک‌های عمومی

## شبکه‌های اجتماعی

برای هر شبکه:

- نوع شبکه
- URL
- وضعیت فعال/غیرفعال
- ترتیب نمایش

Icon بهتر است بر اساس نوع شبکه تولید شود و Icon HTML خام در تنظیمات ذخیره نشود.

## نماد اعتماد الکترونیکی (اینماد)

اینماد یک بخش Presentation و اعتمادسازی در وب‌سایت است و در Theme Management مدیریت می‌شود.

### موارد قابل مدیریت

- فعال/غیرفعال بودن نمایش اینماد
- تصویر/Badge اینماد
- URL رسمی نماد
- شناسه یا اطلاعات نمایشی موردنیاز در صورت نیاز
- متن توضیحی اختیاری کنار نماد
- محل نمایش، با Footer به‌عنوان محل پیش‌فرض

### مدیریت تصویر

تصویر اینماد باید از WordPress Media Library انتخاب شود و Preview، جایگزینی و حذف داشته باشد. فایل یا Base64 نباید داخل Theme ذخیره شود.

### مرز مسئولیت

Theme فقط نحوه نمایش اینماد را مدیریت می‌کند. اعتبار، مالکیت، وضعیت حقوقی یا صحت گواهی اینماد نباید توسط Theme به‌صورت منطقی تأیید یا جعل شود.
