# مدیریت صفحه اصلی

## Hero

مدیر باید بتواند موارد زیر را تغییر دهد:

- Hero Image / Desktop Image
- Mobile Hero Image در صورت نیاز
- عنوان اصلی
- توضیح
- متن و لینک CTA اصلی
- متن و لینک CTA دوم در صورت وجود
- فعال/غیرفعال بودن عناصر اختیاری

## Features

هر Feature شامل:

- عنوان
- توضیح
- Icon یا Image
- وضعیت فعال/غیرفعال
- ترتیب نمایش

مدیر باید بتواند Feature را اضافه، ویرایش، حذف/غیرفعال و جابه‌جا کند.

## How It Works

هر Step می‌تواند شامل:

- شماره یا ترتیب
- عنوان
- توضیح
- تصویر یا Illustration
- لینک اختیاری

Stepها باید قابل افزودن، حذف، ویرایش و مرتب‌سازی باشند.

## سایر Sectionها

هر بخش عمومی صفحه اصلی که در طراحی نهایی وجود دارد باید در صورت نیاز قابل مدیریت باشد:

- عنوان Section
- Subtitle
- متن معرفی
- Image/Illustration
- CTA
- ترتیب Section
- وضعیت نمایش

هدف این است که تغییر محتوای سایت نیازمند تغییر PHP/HTML نباشد.
